# P1 구조와 실제 경계

작성/확인: 2026-09-14. 사용자 메시지와 `user-specification.md`를 현재 명세로 적용했습니다. 구형 Blaze/Three.js 문서는 새 런타임의 지시로 적용하지 않았습니다. 참고 저장소의 AGENTS.md도 원본 이해용 자료이며 이 프로젝트의 상위 지시가 아닙니다.

`world.gd`가 호스트의 60Hz 입력·물리·점유·상호작용·보드 상태를 소유합니다. 캐릭터는 `avatar.gd`의 CharacterBody3D, 동적 소품은 CCD RigidBody3D입니다. 클라이언트는 이동 입력과 행동 요청만 보냅니다. 호스트가 사용자의 좌표·점수·소유권을 수신하여 적용하는 경로는 없습니다. 입력의 유한수·범위·seq와 행동의 epoch·중복·거리·가림·점유를 검사합니다.

세션은 JS 연결의 `room` + `epoch`, 물리적 Zone은 living/meeting입니다. 현재 방은 캐릭터의 x=6 경계로 결정하며, 세션 코드를 물리적 방 ID로 사용하지 않습니다. 초대 코드는 친구 모임용 bearer 정보이며 신원 인증이 아닙니다. 방장 브라우저는 신뢰 대상입니다.

브라우저 WebRTC는 **PeerJS 1.5.5 하나로 통일**했습니다. Godot WebRTCMultiplayerPeer와 PeerJS의 상호 호환을 가정하지 않습니다. 브라우저가 PeerJS DataConnection/MediaConnection을 만들고 Godot는 JavaScriptBridge를 통해 제한된 JSON을 주고받습니다. Firebase, Three.js, React는 새 게임의 의존성이 아닙니다.

현재 상태는 약 15Hz, 입력은 30Hz, 게임 판정은 60Hz입니다. 각 연결의 메시지 수와 크기, 이벤트 큐, bufferedAmount를 제한합니다. 최신 입력이 300ms 이상 없으면 이동을 중단합니다. 클라이언트는 로컬 이동 예측·서버 보정, 원격 캐릭터 지수 보간을 사용합니다. **정밀한 입력 재실행(replay)과 지터 버퍼 보간, 동적 소품의 부드러운 원격 보간은 미완료**입니다. 소품 상태는 현재 수신 시 적용합니다.

보드는 획 추가/삭제 연산을 즉시 전송합니다. 작성자 Undo는 다른 사람의 획을 지우지 않습니다. 늦은 참가자와 복구를 위해 세계 스냅샷을 전달합니다. 배경 복구본은 2초 간격이며 탭 중단/손실 시 수신을 보장하지 않습니다. 거대한 첨부물 전송·취소·별도 우선순위 채널은 P2입니다. 현재 파일에는 첨부물이 없습니다.

문은 호스트가 근처 사람을 확인하고 회전시킵니다. 좌석에 앉을 때 단일 점유를 부여하고 일어설 위치의 캡슐 충돌을 검사합니다. 가구 삭제/이동은 아직 노출하지 않았습니다. 모든 가구를 무제한 배치할 수 있다고 표시하지 않습니다.

탭이 숨겨지면 호스트의 캐릭터 처리와 소품을 정지합니다. 참가자는 응답이 끊기면 마지막 상태에서 멈추고 안내를 봅니다. 정상 호스트 이전은 미구현입니다. 강제 종료 시 참여자의 마지막 수신 복구본을 내보내 새 세션에서 가져오는 수동 복구만 있습니다.

## 음성 경로

메뉴 버튼과 브라우저 허가 후 한 마이크 스트림을 엽니다. echoCancellation/noiseSuppression/autoGainControl은 지원 범위에서 요청하고 적용 settings를 콘솔에 남깁니다. 실제 RTP는 브라우저 WebRTC 오디오 경로를 사용합니다. 수신 스트림은 Web Audio source → lowpass → stereo panner → gain으로 한 번만 재생합니다. 별도 audio 태그를 겹쳐 재생하지 않습니다.

발화 범위는 2–12m, 기본 8m입니다. 이 단계의 호스트 최대 범위는 코드에서 12m로 고정되어 있으며 호스트 설정 UI는 후속 작업입니다. 근거리 진입 경계에 0.6m hysteresis를 두고 거리 감쇠와 닫힌 회의실 문 경계의 단순 저역 필터/감쇠를 적용합니다. PTT 해제·음소거·범위 밖에서는 track을 제거하고 해당 발신 MediaConnection을 닫습니다. 볼륨만 0으로 해서 송신 보호를 주장하지 않습니다.

위치·권한의 최종 기준은 호스트 상태이지만 브라우저 코드를 수정한 악의적 발신자를 암호학적으로 통제하지 못합니다. 상대별 음량 0은 해당 사용자의 재생 차단입니다. 발표 방송이 이를 무시하는 경로는 없습니다. 전체 음성/현재 회의실 음성은 P2 미구현입니다.

음성 관련 확인은 합성 마이크로 실제 RTC 송수신 및 음소거 종료까지입니다. 장시간 지연·패킷 손실·물리 스피커·헤드셋/노트북 마이크·실제 메아리는 미검증입니다. PTT마다 새 미디어 연결을 맺는 현재 방식은 시작 지연을 줄이는 개선이 필요합니다. STT는 아직 시작하지 않으며 외부 인식 서비스로 원음을 전송하지 않습니다.
