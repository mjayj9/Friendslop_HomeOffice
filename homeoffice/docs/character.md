# 제공 남자 캐릭터 검사

5개 원본을 실제 GLB JSON/BIN 구조로 검사했습니다. 모두 skin, skeleton, animation clip이 없습니다. 텍스처 이미지 없이 재질 색상을 사용합니다. 이름의 CC0 표시는 사용자가 제공한 출처 정보이며 별도 원본 라이선스 페이지를 재확인한 것은 아닙니다.

| 원본 번호 | 바이트 | 삼각형 | 실제 내용 |
|---|---:|---:|---|
| 1157 | 483,796 | 6,216 | 서기·앉기·걷기 모양 등 정적 포즈 7개 |
| 1158 | 277,068 | 3,552 | 정적 포즈 4개 |
| 1160 | 138,604 | 1,776 | 손 흔들기·걷기 모양 2개 |
| 1161 | 346,316 | 4,440 | 서기 등 정적 포즈 5개 |
| 1162 | 69,336 | 888 | 걷기 모양 1개 |

여러 포즈 메시가 있다는 것을 애니메이션이 있다고 보고하지 않습니다. 1157의 `Male_Standing`과 `Male_Sitting` 한 종류를 사용했습니다. 서 있는 메시 원래 높이 3.831854 단위를 0.464527배하여 1.78m로 맞추고 발 기준 원점을 정렬했습니다. Blender -Y / glTF +Z 전방을 런타임에서 PI 회전하여 Godot -Z 시점에 맞췄습니다.

새 13본 기본 리그와 신체 부위별 가중치를 Blender에서 작성했습니다. `male-rigged.glb`에는 이 새 스켈레톤이 있습니다. 원본에는 없습니다. 동작은 GDScript의 절차적 본 회전이며 authored AnimationPlayer 클립/AnimationTree는 아직 없습니다. 어깨·팔꿈치 가중치는 거칠며 추가 아트 검토가 필요합니다.

| 동작 | 현재 방식과 상태 |
|---|---|
| 대기 | 제공 standing 메시, 기본 정지 자세 |
| 걷기·달리기 | 새 리그의 다리·팔 절차적 회전, 브라우저 이동 연결 |
| 점프·착지 | 실제 캐릭터 물리 연결, 별도 점프/착지 포즈 미제작 |
| 앉기·일어서기 | 제공 seated 정적 포즈 교체, 좌석 위치와 카메라 높이 연결; 전환 클립 없음 |
| 들기 | 상체 절차적 팔 회전, 제한 속도 물체 그립; 손가락/소품별 손 IK 미완료 |
| 던지기 | 실제 소유권 해제·물리 속도, 던지는 팔 클립 미제작 |
| 보드 쓰기 | 실제 시선-보드면 교점으로 획 생성; 펜촉/손목 정밀 IK 미완료 |
| 눕기·일어나기·농구 슛·도구 조준 | 미구현, P3 신규 클립/절차적 보정 예정 |

로컬 1인칭에서는 전신 시각 메시를 숨겨 머리 안쪽이 보이지 않게 합니다. 다른 사람에게는 제공 남자 전신이 보입니다. **자기 손 전용 1인칭 메시와 세밀한 그립은 남은 작업**입니다. 캡슐은 이동 충돌체이며 시각 캐릭터 대체물이 아닙니다.
