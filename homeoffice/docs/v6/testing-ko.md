# V6 직접 테스트 안내

공개 주소는 [COMMONS WORKSPACE](https://mjayj9.github.io/Friendslop_HomeOffice/)다. 이번 변경은 기존 V4/V5 기능·저장 형식을 보존하는 V6 작업 빌드이며, 전체 인수 완료 판정은 [검수표](verification-ko.md)와 구분한다. 실제 게시 확인은 [배포 영수증](../../evidence/v6/publication/receipt.json)을 기준으로 한다.

1. 입장 뒤 HOME 정문으로 나와 오른쪽 OFFICE로 걸어간다. 1층 로비 안내판 가까이에서 F로 층 안내를 본다. 새 공용 통로는 HOME 동쪽에 있다.
2. 북쪽 홀의 승강기 호출 버튼을 보고 F를 누른다. 문이 열린 뒤 탑승하고 차내 패널에서 층을 고른다. B1, 1F–6F, RF를 연결하며 계단도 실제로 이어진다.
3. 2층 회의실의 화면 가까이에서 F를 누르거나, Tab으로 마우스를 풀고 상단 공동 작업을 연다. 느티나무·이끼·흙빛·세미나 중 참여할 회의를 고른다.
4. 같은 방 초대 코드로 다른 브라우저가 들어와 같은 회의에 참여하면 문서·보드·발표·의제·질문·할 일을 함께 사용한다. 서로 다른 회의의 자료는 분리된다. 원본 자료 탭은 Google Docs/Slides/Microsoft Excel 원본 링크를 연다. 원본 서비스의 계정·공유 권한이 필요하다.
5. 연결이 끊기면 기기에 남길 문서 초안을 편집하고 같은 세션에 다시 연결할 수 있다. 참여 중지가 되면 새 회의 내용은 받지 않는다.
6. 메뉴에서 전체 공간을 내보낸다. 새 단독 세션에서 가져오기를 선택하고 미리보기 뒤 복원한다. 이전 개인실 좌표는 4층 고정 슬롯으로 이동하고 충돌하는 물건은 미배치 보관함에서 유지한다.

조작: WASD 이동, 방향키 시선, C 시점, F 시설 사용, E 집기/내리기, Q 던지기, Tab 마우스, Esc 메뉴. 물건 설치는 옆 패널의 썸네일을 3D 화면으로 끌어 놓는다. 외형 편집은 기존 HOME 의상방 거울/콘솔 현장 클릭으로만 시작한다.

5층 운영실/CCTV·방송실과 스포츠 코트는 검증된 운영 관리자 권한이 필요하다. 첫 방장이나 단독 플레이를 운영 관리자 권한으로 바꾸지 않았다. 이번 게시에서 인증 서버·Firebase·PIN 설정을 바꾸지 않았다.

사람 4명과 실제 마이크, 외부 두 계정 공동편집, 운영 관리자 CCTV/방송, 8인 결합 부하, 체형 극단·스포츠 전문 동작 품질은 아직 인수되지 않았다. 네 개 자동 브라우저 통과를 사람 사용 확인으로 읽지 않는다.
