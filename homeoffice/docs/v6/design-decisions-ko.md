# V6 실제 제작 기준

새 요청은 V6 프롬프트와 네 장의 이미지 분석 및 구현이다. 첨부 문서의 과거 조회·실행 보고는 참고 이력으로 구분하며 현재 확인으로 대신하지 않는다. 원본 이미지 자체는 공개 게임 자산으로 복사하지 않는다.

| 참고 | 자세히 관찰한 요소 | 구현 원리 | 채택하지 않는 요소 |
|---|---|---|---|
| 카페 | 두 층의 넓은 목재 격자 창, 크림 벽 두께, 테라코타 수평 띠, 노란 펜던트, 바닥 타일, 원형 테이블과 바깥 좌석 | 보행 높이에서 안쪽 활동이 보이는 창, 둥근 모서리, 밝은 입면과 실제 앉을 자리 | 흐림으로 접촉/글자를 감추기, 사진 속 인물 복제 |
| 정류장 | 세이지 곡면 지붕, 주황/아이보리 차양, 보도 턱, 벤치, 꽃의 작은 색 대비, 덩어리 크기가 다른 수관 | 입구와 대기 공간을 짧은 보행 흐름에 연결, 잎 대신 덩어리/가지 구조, 재질의 무광 차이 | 버스 운전·도로 시뮬레이션 자동 추가 |
| 도시 조감 | 블록별 낮은 입면, 교차로와 횡단보도, 수목의 반복과 빈 공간, 스포츠의 구분 | HOME/OFFICE/SPORTS의 분리, 층과 입구가 읽히는 안내, 위층 셋백과 정원 | 파일명으로 특정 게임 스크린샷이라고 단정 |
| 사무실 단면 | 중앙 긴 서가/공용 축을 감싸는 순환 통로, 외창을 공유하는 크기가 다른 방, 협업 책상·작은 회의·U형 발표 배치, 지원실 군집 | 중앙 공용 동선에서 여러 크기의 회의실 접근, 창가 업무·안쪽 지원 코어, 문 앞 대기 공간 | 어두운 높은 벽의 그대로 복제, 긴 막힌 복도, 법규 충족 주장 |

팔레트는 제안값 #F1E5D2 / #BC875F / #819B7E / #EDBB58 / #344044이며 사진 픽셀 추출값이 아니다. 물리 단위는 1m, 사용자 남자 GLB와 골격 비율은 유지한다.

구현 순서: 회의별 데이터·권한과 CRDT 재접속 → 대표 미술 장면 → B1~RF 코어·시설·층별 실제 가구 → 기존 기능·저장·공개 웹 검수. 빈 이름표 층이나 단일 렌더를 완료로 부르지 않는다.
