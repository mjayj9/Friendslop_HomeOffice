# COMMONS WORKSPACE 미술·제품 기준

이 문서는 목표와 실제 결과를 구분한다. 아래 기준을 구현/캡처하지 않은 공간은 미완료다.

- HOME: 따뜻한 오크, 거친 석회 벽, 직물, 작은 조명 군집. 거실–식당–주방과 계단–침실–욕실의 생활 동선.
- OFFICE: 중성 석재, 짙은 프레임, 흡음 직물, 정돈된 오크. 도착–회의실–자료–개인실 복도–방송석.
- PLAY: 내구성 콘크리트/고무, 넓은 시야, 경기선과 관전 공간. 전용 경기 공간이 전역 무기 금지 구역을 의미하지 않음.
- 기존 전체 공간과 개인실 확장을 보존한다. 회의실은 현재 `(1.4,4)–(11.4,12)` 바닥 범위와 문·좌석·발표 표면을 유지하며 먼저 마감한다.

## 디자인 시스템
색: warm white #F5F3ED, ink #172D31, muted #5B6F72, evergreen #23544E, accent #C7844D. 위험/연결 실패는 색과 문구를 같이 사용한다.
한글 UI는 기존 라이선스 확인된 Noto Sans KR. 본문 최소 14px, 작은 정보 12px, 클릭 영역 40px 이상. 8px 간격 체계. hover/focus/pressed/disabled/loading/error 상태 분리.
상단은 제품·공간·연결 상태, 하단은 현재 도구와 일관된 키 안내, 오른쪽은 접이식 협업 도구. 게임 시야를 지속적으로 전체 화면 폼으로 덮지 않는 방향.

## 대표 회의실 검수
좌석에서 발표 글자, 출입 동선 0.9m 이상 목표, 책상 높이 약 0.75m 목표, 문틀/천장/걸레받이, 화면과 펜 트레이, 케이블·콘솔, 거친 직물/금속/목재의 차이를 같은 실제 WebGL 프레임으로 평가한다. 수치는 설계 목표이며 법규 인증이 아니다.
Compatibility에서 지원하지 않는 효과를 완성 근거로 쓰지 않는다. 실제 광원과 접촉, 재질 대비를 먼저 조정한다. 생성 이미지/Blender 렌더를 게임 캡처로 제출하지 않는다.
비평 항목: 떠 있는 가구, 문/카메라 가림, 늘어난 UV, 평평한 밝기, 획일적 재질, 너무 큰 UI, 불명확한 상호작용. 각 발견은 화면+Build ID+수정+재시험으로 남긴다.

## 관찰된 시작 상태
`evidence/v4/baseline-v3.png`: 실제 계단·난간·문틀·한글 HUD 존재. 색·광원 대비가 약하고 문 손잡이/벽/목재가 단순하게 보인다. 사용자 미술 인수 통과로 간주하지 않는다.
