# V5 건축·모델·마이그레이션 작업안

현재는 설계 단계다. [상호작용 평면](architecture-plan.html)과 [치수/용도 계약](architecture-plan.json)은 실제 Godot 세계에 아직 적용하지 않았다. 이름이 적힌 공간 수나 도면 면적으로 완성 방을 집계하지 않는다. 64개 영역 중 8개는 개인실 확장 예약 영역이다.

## 공간 구성

HOME은 서쪽, OFFICE는 동쪽, 공개 도착 로비와 중정은 두 동 사이, SPORTS는 별도 남쪽 출입 전실 뒤에 둔다. 일반 방문자가 회의실이나 집 화장실에 갈 때 개인실·침실·관리 코트를 통과하지 않도록 공용 복도를 둔다. 현재 검증은 평면 영역 중첩 0건까지이며, 문 폭과 회전 범위·연속 보행·비상 동선 인수를 대신하지 않는다.

처음 도면에서 HOME 계단이 현관과 0.4m 겹치고, 코트 전실이 농구관에 침범했으며, OFFICE 계단 입구와 홀 사이 간격이 남았다. 이를 수정하고 HOME/OFFICE의 위생 블록을 각각 위아래로 정렬했다. [도면 검토 결과](../../evidence/v5/architecture/design-review.json)와 실제 HTML 렌더를 남겼다.

## 단면과 제작 계약

층고 3.6m의 U 계단은 20단×0.18m, 디딤판 0.30m, 유효 폭 1.5m, 중간 계단참 1.5m를 설계 가정으로 둔다. 중간 Y1.8m, 상부 Y3.6m에서 공용 복도와 실제로 연결해야 한다. 계단 전체 개구부·난간·머리 여유 2.2m 목표를 모델과 충돌체에 함께 적용한다. 기존 계단을 장식으로 덮는 방식으로 구현하지 않는다.

도면의 창 표기는 아직 외벽 우선이라는 방향 수준이다. 창의 실제 위치·폭·창대·블라인드, 각 문의 여닫이와 손잡이, 설비 급배수 모델, 조명 배치, 가구 상세 배치와 복잡한 코너 동선은 미완료다. 건축 인수 T04–T08을 통과했다고 할 수 없다.

GLB마다 단위 m, 바닥 원점, 치수, 눈에 보이는 지지 구조와 collision, 좌석/손/도구 socket, 재료와 표면 프로필, 개별 LOD·삼각형 수·텍스처 예산이 필요하다. 이번 실제 수정은 낮은 테이블 지지 충돌체, 의자/테이블 양손 grip, 소파 세 좌석의 접촉 계약과 원본에서 렌더한 카탈로그 썸네일이다. 새 건물 GLB의 제작·이 계약 전체 적용은 남았다.

## 저장 이동의 활성화 조건

지금 활성화한 저장 보정은 `low_table`이 상판만으로 바닥에 안착해 약 .38m 묻힌 알려진 경우뿐이다. 원본 Dictionary를 복제하고 실제 바닥 ray를 확인하며 같은 보정을 두 번 적용하지 않는다. 테이블 바로 위의 작은 소품도 같은 변위로 이동한다. 다른 가구를 임의로 초기화하거나 개인실·자료를 버리지 않는다.

전체 건축 변경에는 별도 `layoutVersion`이 필요하다. 다음 순서를 구현·검증한 뒤에만 새 좌표를 활성화한다.

1. 원본 저장을 보관하고 schema/asset/layout 버전을 검사한다. 실패하면 현재 세계를 교체하지 않는다.
2. 기존 objectId, 방 슬롯, 문서/보드/수납 참조를 유지한다. 각 구역의 강체 변환으로 좌표와 yaw를 옮긴다. 가구 위 소품은 지지 관계를 함께 옮긴다.
3. 벽·문·슬래브·계단·좌석 접근 공간과 충돌하면 객체를 삭제하지 않는다. 원좌표·종류·참조를 보존한 복구 목록과 실제 검토 위치를 제공한다.
4. 개인실 확장 복도와 입구를 먼저 확정한 뒤 각 사용자 방 내용을 옮긴다. 접근 불가인 방만 이름을 바꾸어 남기지 않는다.
5. 저장 가져오기로 PIN·토큰·서명 개인키·관리자 역할을 복원하지 않는다. 현재 세션에서 실제 인증으로 권한을 재평가한다.
6. 옛 저장→이동→전체 내보내기→재열기와 실패 시 롤백을 같은 빌드에서 시험한다. T47 전체 합격은 그 이후다.

이 절차는 계획이며 아직 구현되지 않았다. 현재 런타임 구조를 바꾸지 않은 이유는 좌표·저장·가구/설비 계약을 함께 완성해야 하기 때문이다.


## 2층 의상방의 제한적 런타임 적용

전체 새 평면과 별개로 기존 독서실의 동쪽 5×7m 영역만 먼저 의상방으로 구성했다. 기존 reading-sofa/table/book 좌표와 ID를 그대로 유지하고 기존 갤러리 출입구와 독서 공간의 개구부를 연결했다. 실제 계단으로 왕복 가능한 위치이며 [현장/편집 검수](wardrobe-review-ko.md)에 현재 GLB와 화면이 있다. 전체 HOME/OFFICE/SPORTS 새 건축의 적용 완료를 뜻하지 않는다.

이 구획과 충돌하는 옛 사용자 가구는 `wardrobe.restore_conflicts`가 복원 전에 탐지한다. 충돌이 있으면 현재 세계와 원본 파일을 유지하고 복원을 중단한다. 임의 삭제·숨김·좌표 덮어쓰기·권한 import는 하지 않는다. 자동 안전 재배치와 새 layoutVersion 전체 마이그레이션은 여전히 구현 대상이다.
